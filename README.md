# Практическая работа №1, Вариант №28

В данной практической работе, мы разработали прототип веб-приложения с поддержкой удалённого вызова процедур на основе протокола TCP.

# main.py
Отвечает за основной функционал приложения, логику работы с данными.
## create_feedback
Отвечает за создание объекта типа feedback. Получает на вход аргументы, согласно заданию.
## create_message
Отвечает за создание объекта типа message. Получает на вход аргументы, согласно заданию.
## create_client
Отвечает за создание объекта типа client. Получает на вход аргументы, согласно заданию.
## create
Отвечает за вызов функций создания объекта при работе через REPL. Считывает на входе название объекта, тип которого надо создать, и затем считывает необходимые для его создания аргументы для последующей их передачи функции создания объекта.
## datatype_match
Получает на входе название типа объекта, и возвращает соответствующий список, хранящий их.
## delete_data
Отвечает за удаление объектов, получая на вход тип и идентификатор объекта.
## edit_data
Отвечает за изменения данных у объекта.
## edit
Отвечает за вызов функции edit_data при работе через REPL.
## select_data
Производит выборку данных согласно условиям задания. Не требует ничего на входе, возвращает пустую таблицу, если по условию ничего не подошло, или возвращает требуемые по заданию поля.
## repl
Отвечает за работу с программой без запуска использования TCP. Доступные команды:
create: считывает на входе название типа функции для создания.
edit: считывает на входе название типа функции и уникальные идентификатор для последующего изменения.
delete: считывает на входе название типа функции и уникальные идентификатор для последующего удаления.
list: считывает на входе название типа функции и выводит список соответствующих объектов.
select: проводит выборку по сохраненным данным согласно заданию варианта.

# client.py
Отвечает за запуск клиента для связи с сервером, отправки корректных запросов.
## start_client
Отвечает за подключение к серверу, отправку запросов и получению ответов.
## send_create_feedback
Формирует корректный запрос для создания объекта типа feedback на основе входящих аргументов.
## send_create_message
Формирует корректный запрос для создания объекта типа message на основе входящих аргументов.
## send_create_client
Формирует корректный запрос для создания объекта типа client на основе входящих аргументов.
## send_edit_data
Формирует корректный запрос для изменения данных объекта на основе входящих аргументов.
## send_select_data
Отправляет запрос на формирование выборки данных согласно варианту.

# server.py
Отвечает за взаимодействия логики приложения (main.py) с клиентом (client.py).
## read
Обрабатывает входящий запрос, проверяя на соответствие шаблону.
## execute
На основе прочитанных данных из входящего запроса вызывает соответствующую функцию и возвращает результат выполнения.
## _flat_reply
Возвращает ошибку в случае возникновения таковой.
## create_reply
Формирует ответ на основе данных полученных в результате выполнения входящего запроса.
## start_server
Отвечает за запуск сервера, прослушивание порта, принятия запросов от подключенного клиента и возврата результата.

# Запуск
Для запуска в режиме работы через REPL запустите main.py через run.bat

Для запуска в виде серверного приложения запустите сервер server.py через run_client.bat
А затем запустите клиент, client.py через run_server.bat

Для запуска тестов в папке tests находится файл, run_tests.bat

# Пример работы
1. Через REPL:
   Введите message для создания объекта типа message.
   Заполните запрашиваемые данные, для данных типа int обязательно указывайте число.
   Аналогично создаются объекты типа feedback и client.
   Для изменения объекта введите тип объекта и идентификатор.
   Укажите новые желаемые данные для объектов, в случае если хотите оставить предыдущее значение, просто нажмите enter.
2. Через клиент-сервер:
   Запустите сервер, а затем клиент.
   Укажите размер xml тела (необязательно указывать точное значение, достаточно чтобы размер тела не превысил его).
   Укажите код операции (от 1 до 5 включительно).
   Заполните запрашиваемые значения.

# Коды операций
При работе через клиент-сервер будут участвовать коды операций, от 1 до 5.
1. Создать объект типа feedback
2. Создать объект типа message
3. Создать объект типа client
4. Изменить объект
5. Провести выборку
